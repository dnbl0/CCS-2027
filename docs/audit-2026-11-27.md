# Code audit, 27 Nov 2026

A whole-repository review on two axes (Matt Pocock's code-review skill): **Standards** (the repo's documented rules plus Fowler's
code smells) and **Spec** (the documented decisions and the site owner's standing rules). Four read-only reviewers covered the
backend, the front end, tests/CI/infra/docs, and the decision records. Tooling at the time: RuboCop clean (651 files), Brakeman 0
warnings. Status column: what has been done about each finding (update it as fixes land).

## Order of work

1. CI safety (this PR): delete `auto-merge.yml`, fix `.agents/rules/pr-workflow.md`, run the Solr tests in CI, read-only tokens.
2. The owner's rules: no counts outside the search results; never crop cultural-object images; write both rules into
   `docs/decisions-2027.md` with tests that fail if they return.
3. Collection-story pictures (PR #91): stop loading them from another site on page load, or load only on request; update
   `docs/compliance-register.md` "Third-party requests".
4. Clean-up: UI text into locales; one Solr phrase/term helper and one list of Solr outage errors; one card shell and one
   breadcrumb; stale docs and ADRs.
